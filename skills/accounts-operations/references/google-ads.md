# Google Ads

Research the [Google Ads API documentation](https://developers.google.com/google-ads/api/docs/start) and [release notes](https://developers.google.com/google-ads/api/docs/release-notes) before every new request.

Verify the supported API version, developer-token access level, manager-account header requirements, GAQL field compatibility, mutate-operation schema, partial-failure behavior, quotas, and current validation-only option. Treat customer and manager ids as account configuration, not user input.
