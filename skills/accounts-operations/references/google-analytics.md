# Google Analytics

Research the [Google Analytics Data API documentation](https://developers.google.com/analytics/devguides/reporting/data/v1) and [Admin API documentation](https://developers.google.com/analytics/devguides/config/admin/v1) before every new request.

Verify Data versus Admin API host and version, property permissions, allowed dimensions and metrics, compatibility, pagination, timezone, currency, sampling, thresholding, retention, and freshness. State when API values are sampled or may differ from the Analytics UI.
