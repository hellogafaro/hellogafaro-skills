# Klaviyo

Research the [Klaviyo API documentation](https://developers.klaviyo.com/en/) and its current revision/version policy before every new request.

Verify the latest stable revision, JSON:API request and response shape, required key scopes, rate-limit tier, cursor pagination, bulk-job lifecycle, and the distinction between private `/api` and public `/client` surfaces. Use only the connected account's private server-side API through Accounts.
