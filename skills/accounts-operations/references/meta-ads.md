# Meta Ads

Research the current [Meta Marketing API documentation](https://developers.facebook.com/docs/marketing-apis/) and [Graph API changelog](https://developers.facebook.com/docs/graph-api/changelog/) before every new request.

Verify the Graph API version, ad-account scope, fields and breakdown compatibility, async-report requirements, pagination cursor, rate limits, attribution window, timezone, currency, and delivery-status semantics. Do not assume campaign, ad set, or ad fields survive a version change.
