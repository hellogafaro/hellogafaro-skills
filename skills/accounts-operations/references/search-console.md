# Search Console

Research the [Search Console API reference](https://developers.google.com/webmaster-tools/v1/api_reference_index) and [performance-data guidance](https://developers.google.com/webmaster-tools/v1/how-tos/all-your-data) before every new request.

Verify property ownership, encoded site URL, search type, date availability, row limit, pagination, aggregation behavior, and quota. State when page or query dimensions can make result totals incomplete or non-additive.
