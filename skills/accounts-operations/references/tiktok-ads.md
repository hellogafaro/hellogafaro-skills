# TikTok Ads

Research the current TikTok Business API documentation for the connected product and its [developer changelog](https://developers.tiktok.com/doc/changelog) before every new request.

Verify the supported Business API version, advertiser scope, access-token behavior, report dimensions and metrics, pagination, async-report lifecycle, rate limits, and whether a field or endpoint belongs to Ads rather than another TikTok product. Do not reuse general TikTok API examples for Ads operations without confirming product compatibility.
