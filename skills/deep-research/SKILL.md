# deep-research

Use this skill when given a topic or question that needs current, external, source-backed research.

Do not rely on snippets. Read full source content where possible.

## process

1. Clarify scope if the research question is ambiguous.
2. Define what done means.
3. Break the topic into 3 to 5 key sub-questions.
4. Browse across at least 8 sources and at least 3 source types when the ask is truly deep.
5. Rank sources by credibility.
6. Check publication dates and mark stale sources on fast-moving topics.
7. Identify gaps after the first pass.
8. Run targeted searches to fill gaps.
9. Cross-reference agreement, disagreement, methodology, recency, bias, and sample size.
10. Never fabricate citations.

## source types

- Primary sources include peer-reviewed papers, official reports, government data, company docs, and product docs.
- Practitioner sources include industry blogs, expert commentary, conference talks, and technical documentation.
- Organic sources include Reddit, YouTube, X, and community threads.

Organic sources are community signal, not primary evidence.

## credibility

Use this hierarchy as a tiebreaker.

1. Peer-reviewed.
2. Official or government.
3. Reputable news.
4. Expert practitioner.
5. Community or organic.

Flag when a conclusion relies heavily on lower-tier sources.

## output

Use this structure unless the user asks for a different format.

1. TLDR.
2. Key findings.
3. Analysis.
4. Consensus.
5. Areas of debate.
6. Gaps and further research.
7. Sources.

Key findings should be 5 to 7 bullets, each anchored to a citation.

Analysis should synthesize across sources rather than summarize each source separately.

Sources should include name, type, URL, and date.

## constraints

- Lead with the most important finding.
- Read full pages where possible.
- Mark inferences clearly.
- Mark contested claims clearly.
- If a sub-question remains unanswered after two passes, say so directly.
- No filler.
