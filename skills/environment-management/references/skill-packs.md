# Skill packs

Source repo for installs: `hellogafaro/hellogafaro-skills`

Install command pattern:

```bash
gh skill install hellogafaro/hellogafaro-skills SKILL ... --agent cursor --dir .agents/skills
```

## Packs

- reporting
