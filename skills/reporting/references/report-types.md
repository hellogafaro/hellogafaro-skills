# report types

Use this when deciding output shape.

## Quick answer

Best for direct questions.

Include:

- Answer
- Evidence
- Confidence
- Limitation if material

## Anomaly memo

Best for sudden movement or alert follow-up.

Include:

- What changed
- Size of movement
- Likely driver
- Confidence
- Next action
- What to watch

## Weekly report

Best for operating review.

Include:

- Client and channel grouping
- Current period numbers
- Prior period numbers
- Problems, clearly separated
- Warnings, clearly separated
- Wins
- Watch items
- Actions

If everything looks healthy, say so briefly.

## Monthly report

Best for client-ready performance review.

Include:

- Executive summary
- Channel performance
- Business result
- Drivers
- Recommendations
- Next period watchouts
- Limitations

Use the selected client-specific template when one exists. Otherwise use the default monthly report template.

Title format in Notion: `Mar 2025 performance report`.

Do not finalize before the 5th unless clearly manual and explicitly requested.
