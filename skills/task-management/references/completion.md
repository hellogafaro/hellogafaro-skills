# Completion

When completing a linked workspace Task, use this order:

1. Inherit the actual duration only when the user supplied it explicitly. Otherwise ask how long the work took.
2. Create and verify the required time entry.
3. Add one concise final comment describing the result.
4. Mark the canonical Task Done.

If the Task is already Done but has missing time, do not reopen it. Ask to repair the time entry.

The final comment is the result log, not a restatement of the original task. Write in first person as the actor who did the work. Prefer two or three short natural prose chunks, adding decisions, links, screenshots, or files only when they help verify the result.

For development tasks, include linked commits, pull requests, deployments, or other code results when they exist. Use natural prose rather than key-value labels.
